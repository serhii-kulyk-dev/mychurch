# Аналітика сайту

Два канали, один набір подій:

1. **Свій лічильник** — усі дані на нашому сервері, покрокова стрічка кожного
   візиту. Кабінет: **`/admin`**, закритий паролем `ANALYTICS_PASSWORD`.
2. **Google Analytics 4** через Firebase — звичні звіти Google, аудиторії та
   рекламні конверсії. Вмикається змінними `NEXT_PUBLIC_FIREBASE_*`;
   без них працює тільки свій лічильник.

Кожен виклик `track()` іде в обидва канали: назви подій збігаються, окрім
`pageview` → `page_view` (так його чекає Google) і заявки, яку GA4 додатково
отримує під стандартною назвою `generate_lead`.

> **Куки й згода.** Свій лічильник куки не ставить. GA4 ставить (`_ga` та
> подібні), тому для відвідувачів з ЄС юридично потрібен банер згоди —
> його поки немає. Вимкнення збору (`?notrack=1` або кнопка на `/privacy`)
> зупиняє обидва канали: SDK Firebase у цьому випадку взагалі не вантажиться.

## Що видно в кабінеті

| Сторінка | Що показує |
|---|---|
| `/admin` | Люди, візити, перегляди, середній час, заявки, конверсія. Графік по днях, воронка з 5 кроків, джерела, сторінки, кліки, побачені блоки, пристрої, країни, години. |
| `/admin/people` | Хто скільки разів заходив: візити в періоді й за весь час, перший і останній візит, час на сайті, заявки. |
| `/admin/people/<id>` | Історія однієї людини: усі візити, у кожному — повна стрічка кроків. |
| `/admin/sessions` | Усі візити періоду; фільтри «із заявкою», «дійшли до форми», «читали». |
| `/admin/sessions/<id>` | Стрічка кроків одного візиту: час, дія, сторінка, деталі. |

Кнопки **CSV** і **JSON** у шапці вивантажують сирі події за вибраний період.
Кнопка **Наживо** оновлює звіт кожні 30 секунд.

## Які кроки записуються

Автоматично (`src/components/shared/analytics.tsx`):

- `session_start` — початок візиту (30 хв без активності = новий візит);
- `pageview`, `page_exit` — відкриття сторінки й скільки секунд на ній пробули;
- `scroll` — 25 / 50 / 75 / 90% прокрутки;
- `section_view` — які блоки реально побачили на екрані;
- `click`, `link_click`, `outbound`, `copy` — кліки з підписом кнопки чи посилання;
- усе, що позначене `data-track="назва"` — наприклад головні CTA (`cta`).

Вручну, через `track()` з `@/lib/analytics/client`:

- `modal_open` / `modal_close` — модалка демо;
- `form_start`, `form_error`, `form_submit` — кроки форми (тексту полів не пишемо);
- `lead` / `lead_failed` — заявка дійшла або ні;
- `builder_pick`, `brief_size`, `brief_tool` — вибір у конструкторі й брифі.

Щоб додати свій крок — або повісьте `data-track="назва"` на елемент, або
викличте `track("назва", { … })` і додайте підпис у `EVENT_LABELS`
(`src/lib/analytics/events.ts`).

## Де зберігаються дані

Драйвер вибирається сам (`src/lib/analytics/store.ts`):

1. **Redis** — якщо задані `UPSTASH_REDIS_REST_URL` і `UPSTASH_REDIS_REST_TOKEN`
   (потрібно на Vercel: там файлова система тільки для читання);
2. **Файли JSONL** — один файл на добу в `ANALYTICS_DIR`
   (типово `.data/analytics/2026-09-19.jsonl`). Підходить для VPS і Docker —
   не забудьте примонтувати теку як том, інакше дані зникнуть із контейнером;
3. **Пам'ять процесу** — запасний варіант, якщо писати нікуди. У логах
   з'явиться помилка, а в кабінеті — підпис, що дані не переживуть перезапуск.

Старіші за `ANALYTICS_RETENTION_DAYS` (типово 400) файли прибираються самі.

## Змінні оточення

```
ANALYTICS_PASSWORD=…        # пароль до /admin; без нього кабінет закритий
ANALYTICS_SECRET=…          # ключ підпису куки (типово — сам пароль)
ANALYTICS_DIR=…             # тека для JSONL (типово <корінь>/.data/analytics)
ANALYTICS_RETENTION_DAYS=400
ANALYTICS_TZ=Europe/Kyiv    # часовий пояс звітів
UPSTASH_REDIS_REST_URL=…    # для serverless
UPSTASH_REDIS_REST_TOKEN=…
```

## Firebase / GA4

Проєкт `my-church-91ac9`, потік `G-5QYNXE91NG`. SDK вантажиться ліниво —
динамічним імпортом уже після першої події, тому на швидкість першого екрана
не впливає. Конфіг лежить у `NEXT_PUBLIC_FIREBASE_*` (`src/lib/analytics/firebase.ts`):
ці значення публічні за задумом, вони однаково потрапляють у браузер.

## Приватність

- Ідентифікатор відвідувача — випадковий рядок у `localStorage`, не куки.
- IP-адреса не зберігається: тільки хеш із щодобовою сіллю, і лише проти флуду.
- Тексти, введені у форми, не збираються — тільки факт кроку.
- Боти відсіюються на прийомі (`/api/track`), у звіт не потрапляють.
- `/admin` закритий паролем, у `robots.txt` заборонений і віддає `x-robots-tag: noindex`.
- Вимкнути збір: кнопка на `/privacy` або `?notrack=1` в адресі. Себе так само
  виключаємо з підрахунку — відкрийте будь-яку сторінку з `?notrack=1`.
